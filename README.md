# Shreya Choudhary — Portfolio

A custom, editorial-style portfolio built with plain HTML, CSS and JavaScript so it can be deployed directly to GitHub Pages.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy

Recommended repository name:

`shreyaChoudhry/shreya-portfolio`

GitHub Pages project URL:

`https://shreyachoudhry.github.io/shreya-portfolio/`

Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.
